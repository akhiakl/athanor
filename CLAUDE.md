# Athanor

Local-first web replatform of Alchemy. Architecture source of truth: `REPLATFORM_SPEC.md`.

## Git conventions

- Branch names: `<type>/<kebab-description>`, for example `docs/replatform-spec` or `feat/render-worker`. Types: feat, fix, perf, refactor, docs, test, build, ci, chore.
- Commit messages and PR titles follow Conventional Commits.
- No attribution trailers or footers in commits or PRs (see `.claude/settings.json`).
- Fill in `.github/pull_request_template.md` for every PR.
